# Acceleration Techniques for Markov Matrix-Based Methods Applied to Fluid Mechanics

This repository presents numerical results obtained using acceleration techniques for Markov matrix-based methods applied to fluid mechanics problems.

The examples included here investigate the influence of obstacle geometry, number, distribution, and characteristic features on the resulting flow fields. The repository contains animations and visualizations illustrating the performance of the proposed methodology under different configurations.

## Contents

* Flow simulations with circular obstacles.
* Flow simulations with square obstacles.


## Objective

The purpose of this repository is to showcase the capabilities of accelerated Markov matrix-based solvers for fluid mechanics applications and to provide visual comparisons of flow behavior under different obstacle configurations.
